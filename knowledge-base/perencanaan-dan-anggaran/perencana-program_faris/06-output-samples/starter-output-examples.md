# Starter Output Examples — Perencana Program (Faris)

## Example 1 — KAK/ToR Draft Pack
- **Task shape:** new or revised program/activity concept.
- **Expected artifact:** structured KAK/ToR pack with objective, scope, outputs, assumptions, dependencies, and reviewer chain.
- **What good looks like:** enough structure for program owner review without pretending approval already exists.

## Example 2 — Program Logic Note
- **Task shape:** user asks whether a plan still fits the intended program logic.
- **Expected artifact:** logic note mapping problem, intervention, outputs, assumptions, and critical dependency risks.
- **What good looks like:** shows where the plan is aligned, stretched, or drifting.

## Example 3 — Scope-Drift Escalation
- **Task shape:** planning draft changes outputs, ownership, or downstream budget/procurement path.
- **Expected artifact:** escalation note naming the drift, affected roles, accountable owner, and rescoping decision needed.
- **What good looks like:** the next reviewer can see immediately why normal progression should pause.
