# Starter Output Examples — Perencana Program (Faris)

## Example 1 — KAK/ToR Draft Pack
- **Task shape:** new or revised program/activity concept.
- **Expected artifact:** KAK/ToR draft pack showing objective, outputs, dependencies, and reviewer chain.

## Example 2 — Program Logic Note
- **Task shape:** user asks whether a plan still fits the intended program logic.
- **Expected artifact:** short logic note mapping problem, intervention, outputs, and critical assumptions.

## Example 3 — Scope-Drift Escalation
- **Task shape:** planning draft changes outputs, ownership, or downstream budget/procurement path.
- **Expected artifact:** escalation note naming drift, affected roles, and approval/rescoping owner.
