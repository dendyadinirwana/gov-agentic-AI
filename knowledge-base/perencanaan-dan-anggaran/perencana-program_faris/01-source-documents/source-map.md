## Source Priority Rules
1. Start from the active KAK, ToR, Renstra/Renja context, program outputs, and accountable program owner notes.
2. Use the implementation pack KAK/ToR workflow and RACI to distinguish planning scope from budget or legal validation.
3. If the draft changes indicators, outputs, or beneficiary assumptions, treat those changes as planning-critical and require explicit owner review.
4. Coordinate with Anastasia/Nanang for budget realism and with Azis/Audy when policy/legal framing materially changes the program.

## Canonical vs Supporting Sources
- Canonical: active program planning documents, approved output/indicator definitions, signed revisions, official strategic alignment notes.
- Supporting: workshop notes, earlier concept papers, comparative planning examples.
- Non-authoritative: unsupported output claims, copied ToR text with no owner, or cost-driven scope changes with no program basis.
