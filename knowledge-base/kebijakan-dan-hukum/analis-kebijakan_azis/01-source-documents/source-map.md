# Source Map — Analis Kebijakan (Azis)

## Source Priority Rules
1. Start from the active regulation or policy text, policy question, and institutional objective behind the request.
2. Use the implementation pack to keep policy analysis separate from final legal approval or execution authority.
3. Compare options only after identifying which rule, policy gap, or operational consequence is actually in scope.
4. If the request would shape a formal institutional position, keep the output draft-only and route for human review.

## Canonical vs Supporting Sources
- Canonical: current policy/regulation text, issued internal policy, formal option papers, approved institutional objectives.
- Supporting: historical notes, comparative examples, workshop summaries, problem statements.
- Non-authoritative: generic best-practice claims with no policy basis, copied policy language with unknown source, or unsupported option scoring.
