# Source Map — Bot Eskalasi (Winda)

## Source Priority Rules
1. Start from the blocker, conflict, or hold context produced by upstream roles.
2. Use the implementation pack governance model, RACI, and action-level policy to identify the accountable human owner.
3. Use shared routing, risk/compliance, and audit references before naming an escalation path.
4. Never invent an approver, accountable officer, or authority chain when the source does not show one.

## Canonical vs Supporting Sources
- Canonical: governance model, RACI, action-level rules, explicit role boundaries, documented approval chains.
- Supporting: prior escalations, issue summaries, review notes, workflow examples.
- Non-authoritative: requester pressure, assumed office hierarchy, or urgency without ownership proof.
