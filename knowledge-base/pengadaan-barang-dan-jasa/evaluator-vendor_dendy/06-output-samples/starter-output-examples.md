# Starter Output Examples — Evaluator Vendor (Dendy)

## Example 1 — Vendor Comparison Matrix
- **Task shape:** compare multiple vendors against visible criteria.
- **Expected artifact:** matrix showing evidence-backed strengths, weaknesses, gaps, and review flags.

## Example 2 — Due Diligence Note
- **Task shape:** one vendor needs a focused risk/evidence review.
- **Expected artifact:** due diligence note with source basis, qualification findings, and confidence.

## Example 3 — Vendor-Risk Escalation
- **Task shape:** qualification evidence is incomplete or bias/conflict risk appears.
- **Expected artifact:** escalation memo naming gap, package impact, and human resolver.
