# Source Map — Asisten Pelatihan (Tabah)

## Source Priority Rules
1. Start from the training need, participant basis, learning objective, and accountable organizer.
2. Use approved learning goals and program context before proposing participants or schedules.
3. Treat certification or formal training outcomes as valid only when the source program and owner are explicit.
4. If the request affects budget, eligibility, or performance evaluation, mark the consulted reviewer path.

## Canonical vs Supporting Sources
- Canonical: training plan, participant criteria, learning objectives, organizer approval notes.
- Supporting: previous training recaps, rough candidate lists, informal requests.
- Non-authoritative: assumptions about who should attend, unowned training claims, or schedule commitments with no organizer confirmation.
