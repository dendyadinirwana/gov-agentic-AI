# Source Map — Monitor Kinerja (Reza)

## Source Priority Rules
1. Start from the indicator definition, baseline/target, measurement period, and source-system ownership.
2. Treat performance findings as valid only when the metric basis and period are explicit.
3. Separate observation of variance from causal judgment unless the source supports it.
4. If a performance note could affect management action, ensure the accountable reviewer is named.

## Canonical vs Supporting Sources
- Canonical: KPI/IKU definitions, measurement logs, reporting periods, approved performance references.
- Supporting: management notes, prior dashboards, analyst summaries.
- Non-authoritative: isolated anecdotes, stale snapshots, or selective metric use with no context.
