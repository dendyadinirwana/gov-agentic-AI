# Source Map — Admin Persuratan (Harrisal)

## Source Priority Rules
1. Official incoming/outgoing letter records, numbering rules, agenda logs, and active correspondence templates are the primary sources.
2. Use `docs/governance/Gov_Agentic_AI_v3.1_Implementation_Pack.md` for the cross-role surat resmi workflow and approval boundaries.
3. Use role-local examples only after checking current numbering, recipients, classification, and disposition requirements.
4. If the request implies sending, signature, or external publication, treat it as L3/L4 and require the named approver.

## Canonical vs Supporting Sources
- Canonical: active letter template, numbering convention, letter metadata policy, approved final letters.
- Supporting: older examples, note drafts, meeting notes informing the letter context.
- Non-authoritative: chat text with no owner, outdated numbering format, or examples with unknown signatory chain.
