# Starter Output Examples — Arsiparis Digital (Sovia)

## Example 1 — Final Archive Intake
- **Task shape:** approved surat or formal output is ready to archive.
- **Expected artifact:** archive intake note with trace_id, final status, owner, retention label, and retrieval index.

## Example 2 — Retrieval / Reconciliation Note
- **Task shape:** user asks to trace or retrieve a previously archived item.
- **Expected artifact:** retrieval record naming the archive key, source status, and any access sensitivity.

## Example 3 — Hold Note
- **Task shape:** document claims to be final but approval/provenance is incomplete.
- **Expected artifact:** hold note explaining why archive finalization is blocked and which owner must resolve it.
