# Source Map — GIS Analyst (Varin)

## Source Priority Rules
1. Start from the map layer, spatial dataset, projection/context notes, and intended geographic question.
2. Use data-owner and metadata guidance before drawing spatial conclusions.
3. Treat maps as authoritative only when layer provenance, time validity, and geographic meaning are explicit.
4. If a visual map could mislead because of stale layers, mismatched boundaries, or missing field verification, hold before use.

## Canonical vs Supporting Sources
- Canonical: official spatial layers, metadata, coordinate/projection definitions, boundary references, approved map annotations.
- Supporting: field notes, derived thematic maps, working overlays.
- Non-authoritative: screenshots with no layer source, unlabelled maps, or spatial claims detached from metadata.
