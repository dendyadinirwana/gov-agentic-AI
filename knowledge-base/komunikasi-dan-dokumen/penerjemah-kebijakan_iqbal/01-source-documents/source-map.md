# Source Map — Penerjemah Kebijakan (Iqbal)

## Source Priority Rules
1. Start from the exact source policy text, intended audience, and translation purpose.
2. Preserve meaning before style; domain terms should stay traceable to the source wording.
3. If the source is ambiguous, mark ambiguity rather than silently normalizing it.
4. Where translation changes public interpretation risk, require reviewer confirmation.

## Canonical vs Supporting Sources
- Canonical: source text, approved terminology, bilingual references, policy owner clarifications.
- Supporting: older translations, public explainers, style suggestions.
- Non-authoritative: loose paraphrases, crowd-sourced term guesses, or simplifications that change policy meaning.
