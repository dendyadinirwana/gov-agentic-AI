# Source Map — Notulis (Anjungan)

## Source Priority Rules
1. Start from the meeting context, participant list, agenda, and any approved recording or note basis.
2. Treat decisions, action items, and PIC assignments as valid only when they are explicitly stated or attributable.
3. Separate what was decided, what was discussed, and what remains open.
4. If action ownership is unclear, keep it unresolved instead of inventing a PIC.

## Canonical vs Supporting Sources
- Canonical: agenda, approved meeting source notes, confirmed attendee list, validated action/decision statements.
- Supporting: rough notes, informal recaps, side comments.
- Non-authoritative: memory-only reconstruction, unconfirmed side agreements, or guessed owners.
