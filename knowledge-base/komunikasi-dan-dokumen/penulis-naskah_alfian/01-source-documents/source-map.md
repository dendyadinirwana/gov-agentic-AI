## Source Priority Rules
1. Start from the approved task objective, message owner, source facts, and template context.
2. Use implementation-pack workflow notes to distinguish drafting support from official issuance or approval.
3. Treat message content as valid only when the underlying facts, audience, and approval path are explicit.
4. If the draft could create legal, public, or institutional impact, ensure the owner and reviewer are named before drafting continues.

## Canonical vs Supporting Sources
- Canonical: approved source facts, current templates, official messaging basis, reviewed prior exemplars.
- Supporting: rough notes, verbal outlines, meeting recaps, old drafts.
- Non-authoritative: rhetorical requests with no factual basis, copied text with unknown owner, or examples mistaken for current policy.
